A podcast with Henry Lachance discussing hallucinations in AI models and how they affect our use of AI. We start off by using ChatGPT to help us make a good prompt to ask for 5 statistics on social medias impact on relationships. We then each use this modified prompt on Deepseek (Henry), and Gemini (Evan) to see if we can find any errors and fact check the response using the link it provides.
